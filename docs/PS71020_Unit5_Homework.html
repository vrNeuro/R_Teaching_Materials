The results suggest that neuroticism and self-esteem account for significant variance in loneliness, R2 = 0.42, F(2, 254) = 90.59, p < .0001. Neuroticism is a significant and positive predictor of loneliness, \(\beta\) = 0.50, t = 9.93, p < .0001, sr2 = 0.23, while self-esteem is a significant and negative predictor of loneliness, \(\beta\) = -0.28, t = -5.47, p < .0001, sr2 = 0.07. The semi-partial correlations suggest around 13% of the variance in loneliness is shared by neuroticism and self-esteem as 6.8% is unique to Self Esteem, 22.6% is unique to Neuroticism.

Below is an example of how to use knitr to produce a nice table of these:

library(knitr)

# 1. Unstandardised coefficients, SE, t, p
co <- summary(mdl)$coefficients

# 2. Standardised betas (drop intercept; names use "Self esteem" not "Self.esteem")
std <- as.data.frame(standardize_parameters(mdl))
std$Parameter <- gsub(" ", ".", std$Parameter)
std <- std[std$Parameter != "(Intercept)", ]

preds <- c("Neuroticism", "Self.esteem")

#this is to reformat p values in APA style
fmt_p <- function(p) ifelse(p < .001, "< .001", sub("^0", "", sprintf("%.3f", p)))

tab <- data.frame(
  Predictor = c("Intercept", "Neuroticism", "Self-esteem"),
  b    = co[, "Estimate"],
  SE   = co[, "Std. Error"],
  beta = c(NA, std$Std_Coefficient[match(preds, std$Parameter)]),
  t    = co[, "t value"],
  p    = fmt_p(co[, "Pr(>|t|)"]),
  sr2  = c(NA, sr2[preds])
)


kable(tab,
      row.names = FALSE,
      digits    = c(0, 2, 2, 2, 2, 0, 3),
      align     = "lrrrrrr",
      col.names = c("Predictor", "*b*", "*SE*", "β", "*t*", "*p*", "*sr*²"),
      caption   = "Regression predicting loneliness")
