What do you notice about the summary output in terms of missing data?

There is no missing data for the condition variable or week 1 but there are increasing amounts of missing data in the subsequent weeks. This is what we’d expect if participants drop out and don’t return.

Our next step is to convert this data to long format, the code to do this is below:

# Wide to long 
df_long <- pivot_longer(df,
                cols            = week_1:week_8,
                names_to        = "week",
                names_prefix    = "week_",
                names_transform = as.integer,
                values_to       = "wellbeing",
                values_drop_na  = TRUE)

Before examining the new df_long dataframe let’s look the code used. Look at the help for the pivot_longer function and what the different optional input arguments mean.

What does the names_to = argument specify?

It is the name of the column we will create using the column names in the df dataframe.

In this case we will create df_long$week

The names_prefix = "week_" and names_transform = as.integer means that we should take a column with a name “week_1” and turn it into a integer value of 1, “week_2” becomes 2 etc. in our new df_long$week variable.

What does the values_to = argument specify?

It is the name of the column we will create using the values in the df dataframe.

In this case we will create df_long$wellbeing which will store the values extracted from the columns selected.

What does the values_drop_na = TRUE argument specify?

This means that instead of copying all the data and having rows in df_long with a NA in the wellbeing column, we will instead just drop (ignore) these rows when creating df_long. So that each row is now an observation with data.

Now we can set up our variables as factors as we have done previously:

We are doing this as we want the first week to act as the reference level (and intercept) when we perform our regressions

SECTION B. VARIOUS APPROACHES TO MODELLING

Repeated measures anova approach

The first approach we could use is a repeated measures ANOVA. However, it needs every student to have a score at every week. Students with any missing weeks are dropped completely (“listwise deletion”).

Also, week must be treated as a FACTOR with 8 categories. Therefore, the model does not know that week 4 comes after week 3.

Here we will run a mixed ANOVA with one between subjects factor and one within subjects factor. Which is which?

Our within subjects factor is week.  

Our between subjects factor is condition,  

#get participants with complete data

#set both ID and week as factors

cc$week_f <- factor(cc$week, levels = 1:8, labels = paste0("wk", 1:8))

What do the results of the ANOVA tell us? What do they not tell us?

1 - We have a main effect of our within subjects factor of week,  

2 - We have a main effect of our between subjects factor of condition,  

3 - We have a significant interaction effect of week and condition.  

4 - We violated the sphericity assumption and a GG correction was automatically applied.  

However, we have no indication of which direction these effects are in so we don’t know which condition is greater than which and we also don’t know which week is different from which other weeks.

We also don’t know if we are observing linear trends (such as wellbeing increasing over weeks) as to the ANOVA the week factor is categorical not ordinal. We could just be seeing one week in the middle being very different from all the others.

We could follow this up with a series of post-hoc tests to try and understand the pattern in our data. However, if we expect linear patterns over weeks we are better using a regression based approach that can account for this.

Standard Regression

We could also model this data using a simple regression, in this case we ignore which student the data comes from and just look at the effect of condition and week and if these factors interact in how they predict wellbeing.

This is what we have done with data with multiple independent participants in weeks 4 and 5.

What are the main results of this approach to modelling this data? Do these results match what you see in the spaghetti plot above

1 - The overall model is significant, so this combination of predictors does explain some of the variance (~14%) in wellbeing scores  

2 - The week0 coefficient (the Control group’s slope) is close to zero & The condition coefficients (differences from Control at week 1) are close to zero.  

3 - There is no main effect of either condition group (compared to control) on wellbeing scores  

4 - There are significant interactions for both conditions and week when explaining wellbeing scores (compared to control*week interaction)  

Yes, roughly we can see that the effect of week on wellbeing is different in the two non-control conditions when compared to control (Control is flat but the other two increase steadily).

The lack of overall effect of week or condition might seem surprising given this, however, the reason is treatment coding: week0 is the slope for the Control group only, and the condition coefficients are group differences at week 1 (week0 = 0). Control doesn’t change over time, and the groups don’t differ at baseline because of random assignment, so both being near zero is expected.

However, we should not trust these results since we are violating one of the key assumptions of linear regression which is independence of observations (or residuals) as we are ignoring the fact that our data is linked by student.

What do the residuals from a regression represent?

They represent the errors of each data point from the predicted value generated by the regression model. The regression fits a straight line through the data that minimises these errors but it is never a perfect fit.

Look at the residuals of the regression, student by student. If the rows were independent these boxes would all sit around zero. Instead each student sits mostly above or below it: their rows are NOT independent.  

NOTE: Uneven number of dots per student is because of missing data for some students.

Individual Regressions

Another approach to analysing data like this would be to fit a separate regression to each student and get the slope of the line over weeks and the intercept (their score at week 1 [week0 = 0]).

What would the formula be to fit a regression to a single participant to examine the effect of week on wellbeing?

wellbeing ~ week0

We don’t need to include condition here as each student only takes part in one condition.

The function below does this and also extracts the ID, intercept, slope and number of observations for that participant:

fit_one_student <- function(d) {
  if (nrow(d) < 3) {
    return(data.frame(id = d$id[1], intercept = NA, slope = NA, n_obs = nrow(d)))
  }
  b <- coef(lm(wellbeing ~ week0, data = d))
  data.frame(id = d$id[1], intercept = b[[1]], slope = b[[2]], n_obs = nrow(d))
}

This bit of code now runs this function, in effect doing 120 little regressions to get one intercept and one slope each.

Two ideas to take away:  

  • Intercepts and slopes really do vary between students: a model with ONE line per group (ordinary regression) ignores this.  

  • However, these separate slopes are noisy: a line through 3 or 4 points is very unreliable  

Part of the spread is real variation, part of it is estimation error.

However, our main question is whether the conditions change at different rates, and a separate regression per student can’t test that. We’d need a second stage: take the 103 slopes and compare them across conditions with a t-test or ANOVA. You will sometimes see this done.

However, that treats each estimated slope as a known, exact number. A slope from 3 weeks of data is weighted the same as one from 8 weeks, and its uncertainty is ignored. The mixed model estimates the group differences and each student’s variation in one step, weighting each student by how much information they provide. This is the usual argument against two-stage analyses.

Another benefit of the mixed-effects approach comes from something called Shrinkage, which we will examine in more detail next week.

Individual regressions answer “what happened for this student?”, and the mixed model answers “what is going on in the population, and how much do students vary around it?”.

Which part of the formula above indicates that the model should allow the intercept to vary per participant?

(1 | id)

The part to the left of the pipe | indicates what should vary according to the bit to the right side of the pipe. In regressions the intercept is denoted by the 1. Both the lm() and lmer() function automatically include the intercept in the formula so when we use a formula like wellbeing ~ week0 * condition what the code actually runs is wellbeing ~ 1 + week0 * condition. With the 1 indicating that the model includes a intercept term. However, when specifying a mixed effects model with individual intercepts we need to include something on the left hand side of the pipe |, so here we use a 1.

In the formula above which are our fixed effects and which are our random effects?

The fixed effects are week0, condition and their interaction, plus the overall intercept (the average Control wellbeing at week 1).

The random effect is the intercept, which varies across id: each student gets their own starting level, shown by (1 | id). Here id is the grouping factor, the thing the observations are clustered within.

What do you notice about how the SEs change between the two modelling approaches?

With the mixed effects model: Between-student terms get larger SEs and within-student terms get smaller ones.

The two kinds of term answer different questions, so the repeated measurements help one and hurt the other.

Between-student terms (the intercept and the condition coefficients) compare different students. Students in a group are different people, so a group difference rests on 120 students, not 802 observations. The rows from one student are highly similar, so the extra rows add little new information. Eight weeks from one student tells you much less than eight different students would. lm() treats every row as independent, so it thinks it has about 802 pieces of information and reports SEs that are too small (1.06 for the condition coefficients). The mixed model knows the real sample size is closer to 120 and gives the larger, more honest SE (1.57). This is also why the df for these terms is about 128.

Within-student terms (week0 and its interactions) compare each student with themselves over time. Here the repeated measurements are an advantage, as in a paired t-test compared with an independent-samples t-test. In lm(), the large differences between students (SD about 6.6) are left in the residual (the errors the model makes), which is why its SE is larger. The mixed model gives each student their own starting level, which removes that variation. What remains is the week-to-week noise, so the effect of week is measured against much less noise. That is why the SEs are smaller (0.14 vs 0.27 for the interaction), and why the df is about 690, close to the number of observations.

However, the within-student SEs in the random-intercept model are still a bit too small, because the model assumes every student changes at exactly the same rate. Next week we will look to correct this by allowing random slopes for each student as well.

SECTION C. A NOTE ON MISSING DATA

Earlier, we noticed that the missing data did not seem to be Missing Completely at Random (MCAR), and drop-out seemed higher for the control group than the other groups. In Week 2 we heard that missing data is a problem when it isn’t MCAR.

More precisely, it’s a problem for methods that only work if the missing data is a random subset of the whole sample, which is what complete-case analysis (like our repeated-measures ANOVA) assumes. Those methods give then give biased answers.

Here the dropout is Missing At Random MAR, not MCAR: who leaves depends on scores we have observed. Likelihood-based methods like mixed models can cope, because they use every observation we do have.

We can see the drop-out is predictable from the scores at week 1, which indicates we are not dealing with MCAR.

df$completed <- ifelse(has_all_weeks, "Completed", "Dropped out")
tapply(df$week_1, df$completed, mean)       # 47.6 vs 41.0
  Completed Dropped out 
   47.64045    40.96774 
t.test(week_1 ~ completed, data = df)       # p < .001

At first it seems problematic that we also observed a difference in drop out rate per group. However, MAR means missingness depends only on information we have observed and modelled. Everyone’s condition is observed, and condition and week0:condition are already in the model. The model fits a separate trajectory for each condition using each group’s own observed data. A condition that loses more students is estimated with less precision, but not with bias, as long as its dropout is explained by group and by scores we’ve seen. However, if we hadn’t included condition in our model then our model would be biased. Similarly, if missingness was predicted by some other factor that we hadn’t measured or included in the model the results would be biased.
